# Quality-Aware Knowledge Distillation of Large Language Models for Efficient Personalised Clinical Report Generation

**MSc Data Science Dissertation — University of Bristol, 2026**

**Author:** Aman Kumar Singh  
**Supervisor:** [Dr Edwin Simpson](https://www.bristol.ac.uk/people/person/Edwin-Simpson-8ec09f42-639a-4b57-9c5b-1708724e9c7a/)

## Overview

This project investigates whether **multidimensional quality-aware knowledge distillation** can improve the quality of personalised clinical reports generated by compact language models.

Using **KBG syndrome**, a rare genetic neurodevelopmental disorder, as a clinical case study, the work explores how a large teacher language model can transfer useful reporting capabilities to a substantially smaller student model. Teacher-generated reports are assessed across multiple dimensions, including **factuality, information coverage, conciseness, and communication quality**, which are used to guide the distillation process.

The approach is evaluated against conventional supervised fine-tuning (SFT), Direct Preference Optimisation (DPO), and an untrained baseline, considering both **clinical report quality and computational efficiency**.

## Research Question

> Can multidimensional quality-aware knowledge distillation improve the clinical quality of reports generated by compact language models compared with conventional supervised fine-tuning?
